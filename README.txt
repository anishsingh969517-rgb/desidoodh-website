# Desi Doodh Website

A responsive, static website for desidoodh.in built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `styles.css` — responsive styling
- `script.js` — mobile menu, current year, WhatsApp contact link
- `assets/favicon.svg` — site icon

## Before publishing
1. Open `script.js`.
2. Change `WHATSAPP_NUMBER = "910000000000"` to your actual WhatsApp number with country code and digits only. Example format for India: `919876543210`.
3. Review product descriptions and contact information and make sure they match your actual business. The site intentionally does not invent an address, prices, delivery promises, certifications or business phone number.

## Publish using Hostinger
1. Download and extract `desidoodh-website.zip` on your phone or computer.
2. Sign in to Hostinger and open **Websites**.
3. If you have a hosting plan, select the website for `desidoodh.in` and open **Manage**.
4. Open **Files → File Manager**.
5. Open the website's document root, usually `public_html`. If this domain is an addon domain, use the document root shown for that domain instead.
6. Upload the contents of the extracted website folder so that `index.html` is directly inside the document root. Do not upload the ZIP alone and do not leave the files nested inside an extra folder.
7. If a default `index.html` already exists, back it up before replacing it.
8. Visit `https://desidoodh.in` and test the page on mobile. Enable/confirm SSL in Hostinger if HTTPS is not active.

If you only purchased the domain and do not have web hosting, you will need a hosting plan or another static hosting provider. A domain registration by itself does not store website files.

## Editing
Edit `index.html` to change wording and product names. Edit `styles.css` to adjust appearance. Edit `script.js` to change the WhatsApp number.
